# Hartwig & Söhne – Handwerker-Website

Moderne, responsive Startseite für einen Meisterbetrieb.

## Lokal starten

### Variante 1: Datei öffnen

Doppelklick auf `index.html` – die Seite öffnet sich im Browser.

### Variante 2: Lokaler Server (empfohlen)

Im Projektordner PowerShell oder Terminal öffnen:

```bash
python -m http.server 3000
```

Danach im Browser öffnen: [http://localhost:3000](http://localhost:3000)

Mit Node.js geht auch `npm start`.
